# DevFlow UI Principles

## 👁️ Visual hierarchy

The current goal, its primary action, and the next decision must be recognizable within seconds. Use size, contrast, position, and whitespace before decoration.

## 🌬️ Whitespace and consistency

Apply the 8pt grid, consistent card padding, predictable labels, and shared component states. Dense project data should remain scannable through grouping rather than smaller text.

## ♿ Accessibility

Maintain semantic structure, visible focus, sufficient color contrast, keyboard paths, descriptive labels, and reduced-motion support. Never rely on hue alone for task status.

## 🖱️ Interaction feedback

Every action receives an immediate state change, loading cue, success confirmation, or clear error recovery path. Destructive actions require intentional confirmation when impact is material.

## ✨ Motion and navigation

Motion clarifies causality: panels enter from their origin, lists preserve context, and modals focus attention. Navigation is stable, keyboard reachable, and keeps workspace context visible.

## 🌙 Dark theme principles

Dark is the default environment, not inverted light mode. Layer depth uses subtle surface shifts and borders; avoid pure black/white contrast, excessive glows, or decorative gradients behind dense content.
