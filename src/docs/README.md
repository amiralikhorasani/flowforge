# DevFlow

## 🚀 Project introduction

DevFlow is an AI-powered project and team workspace for software teams. It brings planning, execution, collaboration, and delivery signals into one focused environment built for developers.

## ✨ Vision

Create the calmest, fastest, and most expressive operating system for modern product engineering teams. DevFlow takes inspiration from excellent tools such as Linear, Notion, Jira, GitHub Projects, Raycast, and Vercel, while defining its own opinionated workflow.

## 💡 Why DevFlow

Teams should not need to trade visual quality for operational clarity. DevFlow combines a premium dark interface, structured project data, keyboard-first navigation, and AI-assisted planning to reduce coordination overhead.

## 🧩 Features

- Multi-workspace team organization
- Projects, tasks, labels, Kanban boards, and sprints
- Calendar, timeline, analytics, and notifications
- Flow Mode and Focus Mode for deliberate work
- Command palette, global search, and responsive dark UI
- Future-facing AI assistance for planning and delivery

See [Features](Features.md), [UX Flow](UXFlow.md), and [AI vision](AI.md) for details.

## 🛠️ Technology direction

DevFlow uses React and Vite today, with a modular route and feature structure. The intended stack includes React Router, Tailwind CSS, Zustand, Framer Motion, React Hook Form, Zod, Recharts, and Lucide icons. Supabase and TanStack Query are planned as backend capabilities mature. See [Tech Stack](TechStack.md).

## ▶️ Getting started

1. Install a current Node.js LTS release.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address displayed by Vite.
