# DevFlow Technology Stack

| Technology | Role and rationale |
| --- | --- |
| React | Component model for interactive product interfaces |
| React Router | Declarative, URL-driven navigation and route protection |
| Tailwind CSS | Fast, token-aligned styling; adoption remains a planned direction |
| Vite | Fast local development and efficient front-end builds |
| TanStack Query | Future server-state cache, synchronization, and mutations |
| Zustand | Lightweight shared client-state store |
| Supabase | Future authentication, Postgres, storage, and real-time layer |
| Framer Motion | Accessible, composable interface motion |
| React Hook Form | Performant, scalable form state |
| Zod | Schema validation at form and service boundaries |
| Recharts | Clear, responsive delivery and progress visualizations |
| Lucide Icons | Consistent, extensible SVG iconography |
| ESLint | Static quality checks and coding-rule enforcement |
| Prettier | Deterministic formatting across contributors |

Technology choices should remain replaceable behind clear feature and service boundaries. Refer to [Architecture](Architecture.md) and [Coding Standards](CodingStandards.md) for adoption rules.
